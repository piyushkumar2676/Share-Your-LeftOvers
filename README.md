# Share-Your-LeftOvers

**Share Your Leftovers** is a web-based food redistribution platform built using PHP, MySQL, and Apache (via XAMPP) — a server-side web platform that connects food donors with recipients and NGOs.
## Problem It Solves

Tons of cooked and surplus food goes to waste daily — from households, restaurants, and events — while many people in the same locality go hungry. Share Your Leftovers bridges this gap by creating a structured, real-time channel for food sharing.

## How It Works

The platform operates on a three-role system:

- **Donors** (individuals, restaurants, event organizers) can post available food with details like quantity, type, location, and pickup window.
- **Recipients** (individuals in need) can browse and request nearby food listings.
- **NGOs / Admins** oversee the redistribution process, verify listings, and coordinate pickups to ensure food safety and accountability.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (core logic, session management, role-based access)
- **Database:** MySQL (user management, food listings, request tracking)
- **Server:** Apache via XAMPP (local development)

## Key Features

- Role-based authentication and dashboards for each user type
- Real-time food listing with availability status
- Request and approval workflow between donors and recipients
- Admin panel for monitoring and managing platform activity

## Purpose

This project was built as part of a hackathon initiative to demonstrate how technology can address real-world social problems — specifically food insecurity and wasteful surplus — at a hyperlocal level.

> "Food wasted is an opportunity missed. This platform turns surplus into support."
